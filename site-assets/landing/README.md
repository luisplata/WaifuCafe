# site-assets/landing

Imágenes del sitio público (`index.html`).

- Nombres y tamaños exactos: ver `docs/landing-images.md`.
- Formato recomendado: `.webp` (fallback `.png`).
- No borrar esta carpeta: el workflow de GitHub Pages la copia a `_site`.
- No usar `assets/` como nombre de carpeta en la raíz: en Windows colisiona con `Assets/` de Unity.
